## About section

I'm a full-stack developer who builds business applications end-to-end — requirements, architecture, backend, frontend, deployment and production support.

Over the last year I built and deployed eight applications for a healthcare tele-consultation company that runs a large call center:

• A call-center CRM (React 19 + Node/Express 5 + SQL Server) that replaced a legacy ASP.NET WebForms app — 47 API modules, dialer/WhatsApp/SMS integrations, 463 models generated from SQL DDL.
• A BI platform with 45+ reports over 50M+ row PostgreSQL/SQL Server tables, using a chunked ETL into a SQLite read-model so reports return in milliseconds; JWT + email OTP; per-report RBAC.
• A real-time WhatsApp Business inbox (MERN + Socket.IO + Exotel API) deployed on Cloudways with PM2.
• A call-quality audit tool with in-page recording playback and a 92 s → 300 ms query optimisation.
• A cached patient lookup (LRU → Redis → SQLite → PostgreSQL), a cohort retention dashboard, a cron-based dropped-call recovery service, and a BullMQ scraping pipeline prototype.

How I work: one clean layered architecture reused across projects, validation at the edge, idempotent integrations, health endpoints, runbooks, and honest documentation of trade-offs.

Stack: JavaScript/Node.js, Express 4/5, React 19, Redux Toolkit, Zustand, TanStack Query, Tailwind, Socket.IO, BullMQ, node-cron, SQL Server, PostgreSQL, MongoDB/Mongoose, SQLite, Redis, ExcelJS, Puppeteer, Winston, Swagger, IIS/iisnode, PM2, Apache, Git.

Open to full-stack / backend roles where I can work with a strong team and keep growing in system design and DevOps.
